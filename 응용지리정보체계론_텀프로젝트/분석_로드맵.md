## 0. 핵심 아이디어 한 줄 요약

> 기존 SOLWEIG 파이프라인(`DSM → SVF → MRT`)을  
> **`GSV 이미지 → Qwen2-VL-7B → 열 노출 점수 → MRT 범주`** 로 대체하고,  
> 동일 연구지역·동일 Thermal Catchment 프레임워크에 적용해 두 MRT 소스를 비교한다.

## 1. 연구 구조 개요

```
[석사논문 (기준선)]                    [텀프로젝트 (제안)]
  기상데이터(S-DoT)                      Google Street View
  건물 DSM                                      ↓
  SVF 계산                            Qwen2-VL-7B MLLM
  SOLWEIG 약식                          구조화 프롬프트
       ↓                                      ↓
  링크별 MRT (°C)         ←비교→      링크별 MRT 추정 범주
       ↓                                      ↓
  Thermal Catchment (Hard Cut 55°C)   Thermal Catchment
  TARR 계산                           TARR 계산
```

**동일하게 유지하는 것**: 연구지역(성동구), OSM 보행 네트워크, 대중교통 정류장, Hard Cut 임계값(MRT≥55°C), TARR 지표  
**교체하는 것**: MRT 소스 (SOLWEIG → MLLM 추정)

#### 모델 선택

| 모델 | 장점 | 단점 | 선택 여부 |
|------|------|------|----------|

| Qwen2-VL-72B | 정확도 높음 | GPU 비용 발생 | 검증용 소규모 비교 |
| GPT-4o | 최고 정확도 | API 비용 $0.005/장 | 예산 초과시 제외 |
| Claude 3.5 | 균형 | 비용 | 대안 |

#### 실행 환경
- **Google Colab** (A100/T4 무료 tier) — `응용지리정보체계론/실습 제출물/` 코드 재활용
- 참고 파일: `qwen_v4.ipynb`, `run_qwen_v4.py`, `walking_eval_colab.ipynb`

#### 프롬프트 설계 (확정안)

```
당신은 도시 열 환경 전문 평가원입니다.
아래 거리 사진은 [서울, 여름 8월 오후 1시 기준 폭염일 조건]의 보행 경로입니다.
사진에서 직접 보이는 것만 근거로 각 항목을 평가하세요.

【그늘 비율】: 현재 경로에서 그늘이 드리울 면적 비율 추정 (0~100%)
【수목 캐노피】: 가로수·녹지에 의한 차양 정도 (없음/낮음/중간/높음)
【건물 차폐】: 건물에 의한 태양 차폐 정도, H/W비 추정 (개활지/반차폐/완전협곡)
【노면 재질】: 아스팔트/콘크리트/블록 등 (복사열 흡수에 영향)
【차양 구조물】: 아케이드, 캐노피, 파라솔 등 인공 차양 유무
【열 노출 점수】: X.X점 (1.0=극고노출 ~ 10.0=완전차폐·쾌적)
【MRT 추정 범주】: 낮음(<45°C) / 중간(45~55°C) / 높음(>55°C)
【종합 평가】: 위 항목을 종합한 열 노출 환경 한 문장

※ 모든 항목 필수 작성. 확인 불가 시 '확인 불가' 기재.
※ 【열 노출 점수】는 반드시 1.0~10.0 소수점 한 자리 숫자 기입.
```

#### 4방향 이미지 → 링크 MRT 집계 방식

```
링크 MRT_score = mean(4방향 열 노출 점수)
링크 MRT_범주  = majority vote(4방향 MRT 범주)
```

#### MRT 수치 변환 (열 노출 점수 → °C)

프롬프트가 출력하는 열 노출 점수(1~10)를 MRT°C로 선형 매핑:

```
열 노출 점수   1.0  ←→ MRT 70°C  (최고 노출)
열 노출 점수  10.0  ←→ MRT 30°C  (완전 차폐)

MRT_est(°C) = 70 - (score - 1) × (40 / 9)
```

> **선택 근거**: 석사논문 성동구 SOLWEIG 결과 범위(42~63°C)와 대응되도록 조정.  
> 최종 보정은 GSV-MRT vs SOLWEIG-MRT 회귀 분석 후 결정.

#### 산출물
```
01_데이터/mllm_mrt_results.csv    # 링크별 8개 항목 + MRT 추정값
```

#### 검증 포인트
- 파싱 실패율 <10% 목표
- 열 노출 점수 분포 히스토그램 확인
- SOLWEIG MRT와 링크별 Pearson r 계산 → 상관 있으면 방법론 타당성 확보

### Step 3. Apply — Thermal Catchment 적용 및 비교 (Day 8~14)

**목표**: MLLM-MRT 기반 Thermal Catchment 산출 → 석사논문 결과와 비교

#### 3-1. 링크 통행 비용 부여

두 가지 방법 모두 구현, 주 분석은 **방법 B(Hard Cut)**으로 석사논문과 직접 비교:

| 방법 | 내용 | 활용 |
|------|------|------|
| **방법 B: Hard Cut** | MRT_est ≥ 55°C 링크를 네트워크에서 완전 제거 | **주 분석** (석사논문 동일 기준) |
| 방법 A: 가중치 | 실질 도보 거리 = 물리 거리 × 열 가중치(MRT 함수) | 보조 분석 |

#### 3-2. Thermal Catchment 재탐색

석사논문 코드 재활용:


새 스크립트: `02_코드/02_thermal_catchment_mllm.py`
```python
# Hard Cut: MRT_est >= 55°C 링크 제거 후 Dijkstra 재탐색
# 출발점: 집계구 중심 → 도착점: 지하철역·버스정류장
```

#### 3-3. TARR 계산

```
TARR_i = (S_i^classic - S_i^thermal_MLLM) / S_i^classic × 100

비교:
TARR_SOLWEIG (석사논문)  vs  TARR_MLLM (텀프로젝트)
```

#### 3-4. 비교 분석 항목

| 분석 | 내용 | 기대 인사이트 |
|------|------|--------------|
| 링크별 MRT 상관 | SOLWEIG MRT vs MLLM MRT (Pearson r, scatter) | MLLM 추정 정확도 |
| TARR 분포 비교 | 두 TARR의 mean·std·분위수 | 방법론 간 차이 크기 |
| 공간 패턴 비교 | Choropleth 지도 나란히 배치 | 고TARR/저TARR 지역 일치 여부 |
| 오차 분석 | MLLM이 크게 틀린 링크 특성 (사진 확인) | 모델 한계 파악 |

## 7. 결과 해석 프레임

### 성공 기준
- MLLM-MRT × SOLWEIG-MRT 상관: **r > 0.5** → 방법론 타당성 주장 가능
- TARR 공간 패턴: **고TARR 지역 70% 이상 일치** → 실용적 대안으로 제시

### 예상 스토리라인
1. MLLM이 **정성적 패턴은 포착**하지만 절댓값 오차 존재 → "빠르고 저렴한 스크리닝 도구"로 위치 설정
2. 고층 건물 그늘이 많은 **성수·왕십리 저TARR** / 서울숲 인근 **개방 공간 고TARR** 패턴이 MLLM에서도 재현되는지 확인
3. MLLM이 틀리는 케이스: 지하 보도·아케이드·야간 촬영분 → 데이터 한계로 논의
