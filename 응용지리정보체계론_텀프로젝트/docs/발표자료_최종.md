## S2. 문제 제기

### 왜 거리 영상 + MLLM인가?

**폭염 → 역세권 보행 가능 범위가 줄어든다**
- 폭염 시 링크별 MRT(평균복사온도)가 임계값 초과 → 해당 구간 보행 기피
- 이 구간들을 제거(Hard Cut)하면 역에서 도보로 닿을 수 있는 지역(Thermal Catchment)이 줄어든다

**기존 물리 기반 MRT 산출의 한계**

| 문제 | 내용 |
|------|------|
| 데이터 의존성 | 고해상도 DSM(건물+수목), 기상 센서망 등 다중 소스 필요 |
| 파라미터 근사 | SVF를 H/W 공식으로, 캐노피를 GIS 면적으로 — 오차 누적 |
| 확장 한계 | 성동구 수준에서도 구축 비용 과다 |

**핵심 질문**
> "거리 영상 한 장으로 링크별 MRT를 물리 공식 없이 바로 추정할 수 있을까?  
> 혹은 물리 공식의 약한 고리(파라미터 추정)를 MLLM으로 보완할 수 있을까?"

## S3. 석사 논문 기반: 기존 MRT 산출 파이프라인

### SOLWEIG 기반 링크별 MRT (선행 연구)

```
OSM 보행 네트워크
    │
    ├── 건물 GIS + 도로 폭 → SVF (Oke 1987 H/W 공식)
    │     SVF = 1 / √(1 + (H_eff / W)²)
    │     H_eff = 건물 평균 높이 + 10m × 캐노피 비율
    │
    ├── 도시숲 SHP → 캐노피 비율 (링크 버퍼 15m)
    │
    ├── S-DoT 57개 센서 → IDW 보간 → 링크별 Tair, RH, Wind
    │
    └── GHI → Erbs(1982) 직산 분리 → 직달·산란 일사
              + Brutsaert(1975) 대기 장파 추정
              → SOLWEIG MRT 공식
              → 링크별 MRT [°C]
                  ↓
              MRT ≥ 55°C → Hard Cut (Thermal Catchment)
```

**근사의 한계**: SVF는 직선 캐니언 단면만 가정 / 알베도 0.70 고정 / 그늘 구조물 미반영

> 이 파이프라인의 결과값이 **본 연구의 비교 기준(Ground Truth)**

```
                    ┌────────────────────────────────┐
  거리 영상          │  Track 1 — 고도화               │
  (카카오 로드뷰)  →  │  MLLM로 파라미터 추출            │
                    │  SVF / 캐노피 / 알베도 / 그늘    │
                    │         ↓                      │
                    │  SOLWEIG 공식에 대입             │
                    │         ↓                      │
                    │  MRT [°C]                      │
                    └────────────────────────────────┘
                           ↓ 비교
                    ┌────────────────────────────────┐
                    │  Track 2 — 대체                 │
                    │  영상 + 기상값 입력              │
                    │  (Tair, RH, Wind, GHI 제공)     │
                    │         ↓                      │
                    │  MLLM 직접 판단                 │
                    │  Low / Moderate / High          │
                    │  (MRT < 45 / 45–55 / ≥55°C)   │
                    └────────────────────────────────┘
                           ↓ 비교
                    ┌────────────────────────────────┐
                    │  Ground Truth                  │
                    │  석사 논문 SOLWEIG MRT           │
                    └────────────────────────────────┘
```

| | Track 1 고도화 | Track 2 대체 |
|-|---------------|-------------|
| 물리 공식 | 유지 (SOLWEIG) | 불필요 |
| MLLM 역할 | 파라미터 추정 | 통합 판단 |
| 기상 입력 | 동일 (IDW 보간값) | 연구자 직접 제공 |
| 평가 지표 | MAE vs SOLWEIG MRT | F1 / Recall (High 탐지) |
| 핵심 리스크 | 파라미터 추정 오차 누적 | 모델 분별력 |

> **Hard Cut(MRT≥55°C) 미탐지가 오탐지보다 위험** → Track 2에서 **High Recall** 중심 평가

## S7. 프롬프트 설계 (UrbanFeel LP 방식)

### 설계 원칙
UrbanFeel의 Local Perception(LP) 접근법: **"시각 근거 먼저 → 추정값"** 순서 강제
→ 근거 없이 수치만 출력하는 hallucination 방지

### 프롬프트 설계 결정 — 파일럿 기반 개선 (v1 → v2)

| 항목 | v1 초안 | v2 수정 | 근거 |
|------|---------|---------|------|
| SVF | 연속값 0.0~1.0 | **범주형 Open/Semi/Enclosed** | 7B도 0.0·0.5 반올림 수준 — 수치 정밀도 없음 |
| 알베도 | 재질명 + 수치 추정 | **제거** | α_k=0.70은 인체 흡수율(Fanger 1970), 바닥 재질과 무관한 고정 상수 |
| 인공 그늘구조물 | 별도 항목(none/partial/significant) | **SVF 추정에 통합** | SVF와 중복 — 교각 있으면 SVF 자체가 낮아야 함 |
| Track 2 HIGH 기준 | 직달 AND SVF>0.5 AND 그늘 없음 | **"보행 경로에 직달일사 도달 여부"** | GHI=750W/m²에서 그늘 없으면 무조건 MRT≥55°C — AND 3개는 과도하게 엄격 |
| Track 2 SVF 수치 | svf_estimate 연속값 | **sky_openness 범주형** | Track 2는 분류가 목적 — 수치 불필요 |

### SVF 범주 기준 (Oke 1987 H/W 기반)

| 범주 | SVF 범위 | 대표 환경 | SOLWEIG 대입값 |
|------|---------|---------|--------------|
| **Open** | > 0.7 | 공원, 한강변, 넓은 대로 | **0.85** |
| **Semi** | 0.4–0.7 | 일반 주거 골목, 소로 | **0.55** |
| **Enclosed** | < 0.4 | 고층 협곡, 고가 아래 | **0.25** |

### Track 1 프롬프트 구조 (v2)

```
[추출 파라미터 — 2개]
  SVF (범주형): Open / Semi / Enclosed
    → 건물·교각·어닝·수목 ALL 포함해서 판단
  캐노피 비율: 0.0~1.0

[출력 JSON]
  {svf_category, svf_confidence, svf_evidence,
   canopy_ratio, canopy_confidence, canopy_evidence}

[코드에서 SVF 수치 변환]
  Open → 0.85 / Semi → 0.55 / Enclosed → 0.25  (Oke 1987 기반)
  → SOLWEIG 공식에 대입
```

### Track 2 프롬프트 구조 (v2)

```
[입력]
  기상값: Tair=35.8°C, RH=61%, Wind=2.4m/s, GHI=750W/m²
  핵심 맥락: "GHI=750W/m²에서 그늘 없으면 MRT≥55°C"

[추론 단계]
  Step 1 — Observe: 하늘 개방도, 그늘 출처, 지표 재질
  Step 2 — Assess: 보행 경로에 직달일사가 닿는가?
  Step 3 — Classify: High / Moderate / Low

[출력 JSON]
  {mrt_category, confidence, solar_exposure,
   sky_openness, shading_source, key_observations, reasoning}
```

### 핵심 발견 1 — 고가도로 케이스 (Track 1, 케이스 4)

> "주변에 건물이 없으면 Oke H/W 공식은 SVF≈1.0으로 계산한다.

- **VLLM T1**: `svf_category=Enclosed`, `evidence="elevated road blocks overhead view"` → **구조물 인식 성공**

## S9. 향후 분석 계획

### 배치 추론 및 비교 분석

```
[Step 1] 코랩 A100/T4 + Qwen2-VL-7B-Instruct-4bit
  → 4,570 링크 × Track 1 / Track 2 각각 추론
  → 결과: vllm_track1_results.jsonl / vllm_track2_results.jsonl

[Step 2] OSMnx 링크 조인 (u, v 키)
  → edges_gdf.merge(vllm_df, on=["u","v"])
  → 반대 방향(v→u) 결과로 NaN 보완

[Step 3] SOLWEIG 비교값 로드
  → 석사 논문 link_utci_sdot_solweig.csv → mrt 컬럼
  → 성수동+응봉동 링크 필터

[Step 4] 평가
  Track 1: MAE (MLLM 추정 MRT vs SOLWEIG MRT)
  Track 2: Accuracy / F1 / Recall (High 범주 특히 집중)

[Step 5] Thermal Catchment 비교 지도
  SOLWEIG 기반 vs Track 1 고도화 vs Track 2 대체
  → 역세권 도달권 축소 패턴 비교
  → TARR (Thermal Accessibility Reduction Rate) 산출
```

### 기대 결과 및 의의

1. **Track 1 > Track 2**: 물리 공식 유지 시 정확도 우위 예상 → 파라미터 추정 정밀도가 핵심
2. **Track 2의 장점**: DSM/SVF 데이터 없이 전국 어디서든 적용 가능 → 확장성
3. **석사 논문 연계**: SOLWEIG 파이프라인 약점(H/W 근사, 알베도 고정) 보완 방안 제시
4. **두 트랙의 상호 보완**: Track 1이 우위면 "파라미터 추정 고도화 유효", Track 2가 우위면 "물리 공식 없는 완전 대체 가능" — 어느 방향으로 결과가 나와도 각 트랙이 상대 트랙의 필요성과 한계를 입증하는 서사 구조
