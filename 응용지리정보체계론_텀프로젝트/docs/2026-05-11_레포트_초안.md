# MLLM 기반 거리 영상 열 노출 평가를 활용한 역세권 Thermal Catchment 분석
**응용지리정보체계론 Final Project | 신진 | 2026-05-11**

---

## 1. 필요성 및 연구배경

기후변화에 따른 도시 폭염 빈도·강도의 증가로 보행 열 환경이 대중교통 이용 행태에 미치는 영향이 주목받고 있다. 역세권 보행 접근성은 단순한 거리·시간이 아닌 **열 노출 수준**에 따라 실질적으로 제약받는다. 이를 정량화하기 위해서는 링크(도로 구간)별 **평균복사온도(MRT, Mean Radiant Temperature)** 또는 **UTCI(Universal Thermal Climate Index)** 산출이 필요하다.

그러나 기존의 물리 기반 MRT/UTCI 산출 과정에는 다음과 같은 어려움이 따른다.

| 문제 | 내용 |
|------|------|
| 데이터 취득 | DSM(건물+수목 높이), SVF, 기상 센서망 등 다중 소스 필요 |
| 방법론 복잡성 | 직산 분리(Erbs 1982) → 장파 추정(Brutsaert 1975) → Stefan-Boltzmann 역산 → UTCI 계산 |
| 간략화 오류 | LiDAR 미확보 시 합성 DSM 사용, 기상 공간 단일값 적용 등 |
| 확장 한계 | 성동구 수준에서도 구축 비용 과다; 서울 전체 확장 시 현실적으로 불가 |

반면, **MLLM(Multimodal Large Language Model)**은 거리 영상(Google Street View)으로부터 건물 형태, 수목 캐노피, 차양 구조물, 노면 재질 등 열 환경 결정 요소를 직접 추론할 수 있다. 본 연구는 MLLM을 활용한 링크별 열 노출 평가 방법론을 제안하고, 이를 Thermal Catchment 분석 프레임워크에 적용하는 것을 목적으로 한다.

## 2. 관련 연구 리뷰

**도시 열 환경 및 보행 접근성**
- Lindberg & Grimmond (2011): SVF 기반 SOLWEIG 모델로 링크별 MRT 산출 — 물리적으로 엄밀하나 고해상도 DSM 의존
- Bröde et al. (2012): UTCI 공식 등급 체계 제시; ≥38°C를 "very strong heat stress"로 정의
- Thermal Catchment 개념(저자 선행 연구): UTCI 기반 Hard Cut을 적용한 역세권 도보 도달권 축소 분석

**거리 영상 기반 도시 환경 평가**
- Li et al. (2015): Google Street View + CNN으로 녹시율(Green View Index) 자동 산출
- Yao et al. (2019): 거리 영상 기반 보행 쾌적성 평가에 딥러닝 적용

**MLLM 활용 도시 환경 평가**
- Qwen2-VL(Alibaba 2024), GPT-4o(OpenAI 2024): 복잡한 도시 장면 이해 및 구조화된 수치 추론 가능
- 수업 실습: Qwen2-VL-7B를 활용한 보행환경 항목별 점수화 및 순위화 성공적 수행

## 3. 연구지역 및 연구방법

### 연구지역
서울특별시 성동구 지하철역 7개소 (응봉·성수·왕십리·행당·뚝섬·서울숲·옥수)
- 기존 TAVI 연구 동일 지역 → 선행 분석 결과와 직접 비교 가능

### 연구방법

```
[Step 1] 거리 영상 수집
  Google Street View Static API
  → 역세권 보행 네트워크 링크 중심점 좌표 기반 크롤링
  → 4방향(전·후·좌·우) 이미지, 여름철 시기 필터링

[Step 2] MLLM 기반 링크별 열 노출 평가
  Qwen2-VL 또는 GPT-4o
  → 구조화 프롬프트: 그늘 비율, 수목 캐노피, 건물 H/W비, 차양 구조물, 노면 재질
  → 출력: 열 노출 점수(0-10) + 정성 서술 + MRT 추정 범주(낮음/중간/높음)

[Step 3] Thermal Catchment 적용
  MLLM 열 노출 점수 → 링크별 통행 가중치(또는 Hard Cut 기준)
  → 기존 TAVI 프레임워크(networkx 기반) 재사용
  → Classic vs. Thermal Catchment 비교

[Step 4] 검증
  MLLM 열 노출 추정값 vs. SOLWEIG 기반 MRT 비교 (Pearson r)
  → 방법론 타당성 검토
```

## 4. 활용 예정 MLLM 모델 및 프롬프트 초안

### 모델 비교

| 모델 | 제공사 | 특징 | 비용 |
|------|--------|------|------|
| **GPT-4o** | OpenAI | 최고 수준 이미지 이해·수치 추론 | API 유료 |
| **Claude 3.5 Sonnet** | Anthropic | 구조화 출력 우수, 한국어 강점 | API 유료 |
| **Qwen2-VL-7B** | Alibaba | 오픈소스, 수업 실습 경험 있음 | 무료(로컬/Colab) |
| **Gemini 1.5 Pro** | Google | 스트리트뷰 연계 가능성 | API 유료 |

→ **1차 실험**: Qwen2-VL-7B (수업 실습 경험, Colab 무료 실행 가능)  
→ **비교 실험**: GPT-4o (정확도 검증용)

### 프롬프트 초안 (열 노출 평가용)

```
당신은 도시 열 환경 전문 평가원입니다.
아래 거리 사진은 [서울, 여름 오후 1시 기준 폭염일 조건]의 보행 경로입니다.
사진에서 직접 보이는 것만 근거로 각 항목을 평가하세요.

【그늘 비율】: 현재 경로에서 그늘이 드리운 면적 비율 추정 (0~100%)
【수목 캐노피】: 가로수·녹지에 의한 차양 정도 (없음/낮음/중간/높음)
【건물 차폐】: 건물에 의한 태양 차폐 정도, H/W비 추정 (개활지/반차폐/완전협곡)
【노면 재질】: 아스팔트/콘크리트/블록 등 (복사열 흡수에 영향)
【차양 구조물】: 아케이드, 캐노피, 파라솔 등 인공 차양 유무
【열 노출 점수】: X.X점 (1.0=극고노출 ~ 10.0=완전차폐·쾌적)
【MRT 추정 범주】: 낮음(<45°C) / 중간(45~55°C) / 높음(>55°C)
【종합 평가】: 위 항목을 종합한 열 노출 환경 한 문장

※ 모든 항목 필수 작성. 확인 불가 시 '확인 불가' 기재.
※ 【열 노출 점수】는 반드시 1.0~10.0 소수점 한 자리 숫자 기입.
```

## 5. 기대 효과 및 의의

1. **데이터 구축 비용 절감**: DSM, SVF, 기상 센서망 없이 무료 거리 영상으로 대체
2. **시각적 맥락 통합**: 물리 공식이 놓치는 요소(아케이드, 지하 통로, 차양막) 포착
3. **확장성**: API 호출만으로 서울 전체·전국 확장 가능 → 검증 문제 해소
4. **연구 가성비**: 기존 Thermal Catchment 프레임워크 재사용, MRT 산출 단계만 교체
5. **석사 논문 연계**: 성동구 비교 분석으로 TAVI 방법론 고도화 기여
