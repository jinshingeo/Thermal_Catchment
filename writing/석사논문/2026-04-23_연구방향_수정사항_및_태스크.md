## 2. 개념 변경 상세

### 2-1. 분석 기점 변경: 역 → 집계구

기존에는 역(7개)에서 catchment를 그렸다면, 이제는 **집계구 중심점(570개)에서 출발**해서 30분 내 도달 가능한 대중교통 정류장을 탐색하는 방향으로 전환합니다. 수요자(주민) 중심의 접근성 분석으로, "성동구 어느 집계구가 대중교통에 얼마나 접근 가능한가"를 직접 측정합니다.

### 2-2. 공급 대상 확장: 지하철 → 지하철 + 버스정류장

- **지하철역**: 기존 7개 그대로
- **버스정류장**: `stops.txt` (GTFS 형식, 좌표 포함, 2026-04-23 추가)
  - stops.txt는 이미 위경도 보유 → 지오코딩 불필요
  - 교수님 언급 "지오코딩+아이소크론+인터섹트" 의미:
    - 지오코딩: 이미 완료 (lat/lon 포함)
    - 아이소크론: 각 집계구 기점에서 30분 catchment 생성
    - 인터섹트: catchment 내 포함되는 정류장 공간 탐색
  - **현 단계에서 지하철-버스 간 가중치 차이 없음** (동등 취급, 추후 고민)

### 2-3. 방법론 변경: G2SFCA → 중력모형 (Gravity Model)

$$A_i = \sum_{j \in \text{catchment}(i)} W_j \cdot G(t_{ij},\ t_0=30\text{min})$$

$$G(t,\ t_0) = \exp\left(-\frac{1}{2}\left(\frac{t}{t_0}\right)^2\right)$$

- $A_i$: 집계구 $i$의 대중교통 접근성 지수
- $W_j$: 정류장 $j$ 가중치 (현 단계: 지하철 = 버스 = 1)
- $G$: Gaussian 거리감쇠 함수 ($t_0$ = 30분)
- catchment: Classic 또는 Thermal (UTCI ≥ 38°C 링크 제거)

**G2SFCA 대비 차이**: G2SFCA는 공급-수요 경쟁비율(R_j)을 계산하지만, 중력모형은 집계구 → 각 정류장 감쇠 가중합을 직접 계산합니다. 중력모형에서는 구조적으로 $A_i^{thermal} \leq A_i^{classic}$이 항상 성립하며 G2SFCA의 경쟁 감소 역설이 발생하지 않습니다.

### 2-4. 캐치먼트 개념 및 지표

| 종류 | 정의 |
|------|------|
| **Classic Catchment** | 전체 보행 네트워크 기준 30분 도달권 |
| **Thermal Catchment** | UTCI ≥ 38°C 링크 제거 후 30분 도달권 |
| **Thermal-robust** | Thermal 조건에서도 접근성 유지 비율이 높은 집계구 (TARR 낮음) |
| **Thermal-prone** | Thermal 조건에서 접근성 급감 집계구 (TARR 높음) |

**분류 기준(Thermal-robust / Thermal-prone)**: 분석 결과 분포 확인 후 결정.

## 3. 접근성 손실 지표 — 두 가지 병행 보고

### TARR: Thermal Accessibility Reduction Rate (비율적 손실)

$$\text{TARR}_i\ (\%) = \frac{A_i^{classic} - A_i^{thermal}}{A_i^{classic}} \times 100$$

- 기저 접근성 대비 상대적 손실 — **어느 집계구가 비율적으로 취약한가**
- 범위: 0 ~ 100% (중력모형에서 역설 없음)

### 절대 손실: Absolute Accessibility Loss (실질적 손실)

$$\text{AAL}_i = A_i^{classic} - A_i^{thermal}$$

- 실제 접근성 박탈량 — **어느 집계구가 절대적으로 많이 잃었는가**

> **두 지표를 병행 보고하는 이유**: TARR은 기저 접근성이 낮은 지역에서 과장될 수 있고, AAL은 원래 접근성이 좋은 지역의 손실을 강조한다. 두 지표가 서로 다른 공간 패턴을 보일 경우, 이 차이 자체가 형평성 분석의 근거가 된다.
