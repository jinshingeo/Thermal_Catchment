## 1. Hard Cut 작동 불가 (폭염일 13시)

- UTCI ≥ 38°C 초과율: **99.8%** (전체 15,608개 링크 중 15,584개)
- 전 역 Thermal Catchment ≈ 0 → 역별 공간 비교 불가
- 원인: UTCI 변환 시 공간 분산 압축 (MRT std=4.6°C → UTCI std=1.7°C) + 폭염일 절대값 상승

## 2. 출퇴근 시간대 분석 신뢰 불가 (IDW 아티팩트)

- 09시 vs 18시 UTCI 공간 상관계수: **r = 0.091** (사실상 무관)
- 원인: S-DoT 57개 센서 → IDW 보간 시 Tair 공간 패턴이 시간대별로 무작위 변동
  - Tair 09시 vs 18시: r = -0.052
- 결과: 어느 역이 출근에 취약하고 퇴근에 취약한지가 물리적 현상이 아닌 IDW 노이즈에 의해 결정됨
- 행당역 09시 57.6% 감소 / 뚝섬역 18시 99.9% 감소 → 신뢰 불가

## 3. MRT는 공간 패턴이 안정적

- MRT 09시 vs 13시: **r = 0.985** (SVF·태양 기하학 기반 → 물리적으로 의미 있음)
- MRT 09시 vs 18시: r = -0.373 (아침=동향, 저녁=서향 도로 가열 → 실제 태양 방향 효과)
- UTCI는 IDW Tair가 공간 패턴을 오염시킴
