# 🌡️ 1부. 열환경 지표

## 1-1. MRT (Mean Radiant Temperature) — 평균복사온도

### 한 줄 정의
사람 몸 주변에서 사방에서 날아오는 **복사열의 총합**을 하나의 온도로 표현한 값

### 쉬운 설명
여름에 아스팔트 위에 서 있으면 발밑에서 열이 올라오고, 해가 위에서 내리쬐고, 옆 건물 벽도 달궈져서 사방에서 열이 날아옵니다. 이 **사방의 복사열을 모두 합쳐** 하나의 온도로 표현한 것이 MRT입니다.

기온(공기 온도)과 다릅니다. 그늘 속에서는 기온이 같아도 MRT가 훨씬 낮습니다. 직사광선 아래에서는 기온 30°C여도 MRT는 60~70°C까지 올라갑니다.

- 그늘진 골목: 기온 35°C → **MRT ≈ 42°C**
- 한강변 개방 공간: 기온 35°C → **MRT ≈ 65°C**

### 계산 공식
$$T_{mrt} = \left[\frac{K_{sw} + L_{lw}}{\sigma}\right]^{0.25} - 273.15$$

- $K_{sw}$: 단파복사 (태양 직달·산란광)
- $L_{lw}$: 장파복사 (건물·지면·대기 적외선)
- $\sigma = 5.67 \times 10^{-8}$ W/m²K⁴ (Stefan-Boltzmann 상수)

### 이 연구 결과
| 항목 | 값 |
|------|-----|
| 분석 시간 | 13시 (폭염 피크) |
| MRT 평균 | **54.1°C** |
| MRT 범위 | 42~66°C |
| 표준편차 | 6.8°C |
| 임계값 | **55°C** (UTCI 38°C 역산) |

### 왜 MRT를 썼나?
폭염 조건에서 기온·UTCI는 공간 차별화가 불가능(99.9% 포화). MRT는 SVF(하늘열림 정도)에 따라 공간 변이(42~66°C)가 안정적으로 유지되므로 유일하게 쓸 수 있는 지표였습니다.

## 1-2. UTCI (Universal Thermal Climate Index) — 범용 열기후 지수

### 한 줄 정의
기온·습도·바람·복사열 네 가지를 합쳐 **사람이 실제로 느끼는 열 스트레스**를 하나의 숫자로 표현한 국제 표준

### UTCI 등급
| UTCI | 등급 | 체감 |
|------|------|------|
| 26~32°C | Strong | 더움 |
| 32~38°C | Very Strong | 매우 더움 |
| **≥ 38°C** | **Extreme** | **보행 위험** |

### 이 연구에서의 역할
직접 사용 실패 → **임계값 역산에만 사용**
- 폭염 13시 조건: 전체 링크의 **99.9%가 UTCI ≥ 38°C** → 공간 차별화 불가
- 우회: UTCI=38°C가 되는 MRT를 역산 → **MRT ≈ 55°C** 도출
- 이후 MRT ≥ 55°C 기준으로 분석 진행

---

## 1-3. SVF (Sky View Factor) — 하늘열린비율

### 한 줄 정의
특정 지점에서 **하늘이 얼마나 열려있는가** (0=완전 막힘, 1=완전 개방)

### 핵심 역설
SVF **낮음** (빽빽한 건물) → 그늘 많음 → MRT **낮음** → 보행 안전  
SVF **높음** (개방 공간) → 햇볕 그대로 → MRT **높음** → 보행 위험

한강변·서울숲 같은 개방 공간이 오히려 폭염에 더 취약한 이유입니다.

### 회귀분석 결과
SVF ↑ → TARR ↑ (양의 상관) — 개방 공간 집계구일수록 접근성 손실 심함

---

## 1-4. GHI / DNI / DHI — 태양 복사 에너지 세 성분

| 약자 | 의미 | 역할 |
|------|------|------|
| **GHI** | 전체 일사량 (직달+산란) | Open-Meteo에서 받아오는 값 |
| **DNI** | 직달 일사량 | 그림자 있으면 차단되는 성분 |
| **DHI** | 산란 일사량 | 그늘에서도 받는 성분 |

$$GHI = DNI \times \cos\theta + DHI$$

- **Erbs 모델**로 GHI 하나에서 DNI, DHI 분리 계산
- 13시 폭염일 평균 GHI = **607.6 W/m²**
- 한계: 전 구역 동일값 적용 (공간 변동 미반영)

---

## 1-5. IDW (Inverse Distance Weighting) — 역거리 가중 보간법

### 한 줄 정의
센서가 없는 지점의 값을 **가까운 센서일수록 더 많이 반영**해서 추정

$$\hat{Z}(x) = \frac{\sum w_i Z_i}{\sum w_i}, \quad w_i = \frac{1}{d_i^2}$$

### 이 연구에서의 역할
- S-DoT 57개 센서 → IDW → 링크 15,608개에 Tair, RH 보간
- 풍속(va)은 전 구역 균일값 2.37 m/s (편차 작아서)

### 한계
- 57개 센서로 16.86 km² 커버 → 보간 오차 가능
- UTCI 계산에서 아티팩트 발생 → MRT 방식으로 전환 이유 중 하나

---

## 1-6. SOLWEIG & Erbs 모델

### SOLWEIG
Lindberg & Grimmond(2011) 개발. 도시 내 복사 환경을 시뮬레이션하여 MRT를 계산하는 모델.  
이 연구에서는 소프트웨어 대신 **핵심 수식을 Python으로 직접 구현** (약식 적용).

**단파복사 항**: $K_{sw} = \alpha_p[(1-SVF) \cdot K_{dif} + shadow \cdot K_{dir} \cdot \cos\theta + SVF \cdot K_{dif}]$  
**장파복사 항**: $L_{lw} = \epsilon_p[SVF \cdot L_{sky} + (1-SVF) \cdot L_{wall}]$

| 파라미터 | 값 |
|---------|-----|
| 인체 흡수율 $\alpha_p$ | 0.70 |
| 인체 방출률 $\epsilon_p$ | 0.97 |
| 벽면 온도 가정 | Tair + 5 K |

### Erbs 모델
GHI 하나에서 DNI와 DHI를 분리해주는 경험적 공식. Open-Meteo GHI → DNI + DHI 변환에 사용.

# 🗺️ 2부. 접근성 분석

## 2-1. Catchment Area — 역세권

### 한 줄 정의
특정 지점에서 **일정 시간 내 걸어서 도달할 수 있는 공간 범위**

직선 거리 원이 아니라 **실제 도로망을 따라** 이동 가능한 범위를 계산합니다.

### 알고리즘: Dijkstra 최단 경로
```
집계구 중심 노드 → TIME_BUDGET(900초) 이내 탐색
→ 도달 가능 정류장 노드 카운트 = Classic_cnt
```

### 이 연구 결과
- 유효 집계구 (Classic_cnt > 0): **506개**
- 평균 접근 정류장: **40.6개**

---

## 2-2. Hard Cut — 이분법적 링크 제거

### 한 줄 정의
MRT 임계값 이상인 도로 구간을 **완전히 통행 불가**로 처리

- MRT ≤ 54.9°C → 통과 가능 ✅
- MRT ≥ 55.0°C → 통과 불가 ❌

### 13시 기준 결과
제거 링크: **3,010개 (19.3%)**

### 왜 Hard Cut인가?
| 대안 | 이유 |
|------|------|
| Soft Penalty (속도 감소) | 접근성이 면적이 아닌 점수로 표현됨 → Catchment Area 개념화 불가 |
| **Hard Cut (이 연구)** | "Thermal Catchment Area"라는 면적 단위 개념 성립 |

Madina(Sevtsuk & Alhassan 2025) 프레임워크에서 Hard Cut = perceived distance의 이진화 특수 케이스로 인용 가능.

---

## 2-3. Thermal Catchment Area — 열환경 반영 역세권

### 한 줄 정의
MRT ≥ 55°C 링크를 제거한 뒤 **실제로 걸어갈 수 있는 범위**

$$C_i^{thermal} = \{j \in G^{thermal} : d_{ij}^{thermal} \leq 15\text{분}\}$$

### Classic vs Thermal 비교
| | Classic | Thermal |
|---|---|---|
| 네트워크 | 전체 | MRT ≥ 55°C 링크 제거 |
| 평균 접근 정류장 | 40.6개 | 10.9개 |

### 왜 새로운가?
기존 연구: 열환경 → 보행 속도 ↓ (연속적 감소)  
이 연구: 열환경 → **접근 가능 공간 범위 자체가 줄어듦** (이분법적 공간 단위)

---

## 2-4. TARR (Thermal Accessibility Reduction Rate) — 열 접근성 감소율

### 공식
$$\text{TARR}_i = \frac{S_i^{classic} - S_i^{thermal}}{S_i^{classic}} \times 100 \quad (\%)$$

### 해석
| TARR | 의미 |
|------|------|
| 0% | 폭염에도 접근성 변화 없음 |
| 50% | 갈 수 있던 정류장 절반 차단 |
| 100% | 완전 차단 |

### 이 연구 결과
| 지표 | 값 |
|------|-----|
| 평균 TARR | **72.9%** |
| 표준편차 | 23.5% |
| 중앙값 | 78.1% |
| TARR = 0% | 51개 집계구 |
| TARR = 100% | 87개 집계구 (17.2%) |

---

## 2-5. TIME_BUDGET & WALK_SPEED

| 파라미터 | 값 | 근거 |
|---------|-----|------|
| TIME_BUDGET | **15분 = 900초** | 15분 도시 개념, 국제 표준 |
| WALK_SPEED | **4.5 km/h = 1.25 m/s** | 성인 평균 보행 속도 |
| 도달 가능 최대 거리 | **≈ 1.1 km** | 4.5 × 15/60 |

**링크 travel_time 계산**: $\text{travel\_time} = \text{length(m)} / \text{WALK\_SPEED}$

향후 과제: WALK_SPEED = 3.0 km/h로 노인 보행 속도 적용 재분석

# 🎲 3부. 불확실성 분석

## 3-1. Monte Carlo 분석

### 한 줄 정의
"55°C" 하나 대신 **가능한 임계값을 2,000번 바꿔가며** TARR 분포를 확인

### 절차
1. 임계값 그리드 9개 [45, 49, 51, 53, 55, 57, 59, 61, 65°C] → 집계구별 TARR 사전 계산
2. threshold ~ N(55, 4²) 에서 2,000회 샘플링
3. 그리드 TARR에서 선형 보간 → 집계구별 TARR 분포 획득
4. 중앙값 + 95% CI 산출

### 결과
| 지표 | 값 |
|------|-----|
| TARR 중앙값 | **70.2%** |
| 95% CI | 0.3% ~ 98.3% |
| 단일 임계값(55°C) | 73.3% |

**CI 폭이 넓은 이유**: 오류가 아니라 53~57°C 구간에서 TARR가 급변하는 민감 구간이 존재하기 때문.

**이 연구에서의 위상**: 메인 분석이 아닌 **검증** — "55°C 결과가 불확실성에도 방향이 맞다"는 확인.

---

## 3-2. S자 곡선 — 임계값 민감도의 핵심 발견

MRT 임계값을 높여갈수록 TARR가 **S자 모양으로 급감**하는 패턴

| MRT 임계값 | TARR 평균 |
|-----------|---------|
| 45°C | 99.8% |
| 53°C | 88.6% |
| **55°C** | **73.3%** |
| **57°C** | **39.0%** |
| 65°C | 0.6% |

**핵심**: 55→57°C 단 2°C 차이에서 TARR가 34.3%p 급락

### 의미
1. **55°C가 의미 있는 임계점**임을 네트워크 구조 측면에서 검증
2. 이 구간 링크들이 네트워크 연결성의 핵심을 담당하는 **교량 링크**임을 시사

## 3-3. Bridge Links — 교량 링크

### 한 줄 정의
제거했을 때 **네트워크 전체 연결성이 급격히 무너지는** 핵심 도로 구간

그래프 이론에서 Bridge = 제거 시 그래프가 분리되는 엣지

### 정책적 함의
교량 링크(MRT 53~57°C 구간)에 집중적으로 그늘막·쿨링 스트리트를 설치하면 → 전체 접근성 회복 효과 극대화

# ⚖️ 4부. 중력모델

## 4-1. 중력모델 (Gravity Model)

### 한 줄 정의
가까울수록, 노선이 많을수록 **더 많이 가중해서** 접근성을 계산

$$A_i = \sum_{j \in S} S_j \cdot \exp\left(-\frac{1}{2}\left(\frac{t_{ij}}{t_0}\right)^2\right)$$

- $S_j$: 정류장 $j$의 노선 수
- $t_{ij}$: 이동 시간(초)
- $t_0 = 900$ (15분)

### 단순 카운트와의 차이
| | 단순 카운트 TARR | 중력모델 |
|---|---|---|
| 거리 반영 | ❌ (15분 이내=1, 외=0) | ✅ (Gaussian 감쇠) |
| 정류장 질 | ❌ (모두 동일) | ✅ (노선 수 가중) |

### 결과
| 지표 | Classic | Thermal | 감소율 |
|------|---------|---------|-------|
| A 평균 | 89.23 | 24.77 | **72.8%** |
| 단순 카운트 | — | — | **72.9%** |
| 상관계수 r | — | — | **0.979** |

---

## 4-2. Gaussian Decay — 거리 감쇠 함수

$$f(t) = \exp\left(-\frac{1}{2}\left(\frac{t}{t_0}\right)^2\right)$$

| 이동 시간 | 감쇠값 | 의미 |
|---------|--------|------|
| 0초 | 1.000 | 100% 기여 |
| 7.5분 (450초) | 0.882 | 88% 기여 |
| **15분 (900초)** | **0.607** | **61% 기여** |
| 30분 (1800초) | 0.135 | 14% 기여 |

Hard Cut = Gaussian의 이진법 극단 케이스 (15분 이내=1.0, 초과=0)

---

## 4-3. Robustness — 방법론 안정성

### 한 줄 정의
**어떤 방법을 써도 같은 결론이 나온다** — 결과가 방법론 선택에 좌우되지 않음

### r = 0.979의 의미
- r이 낮았다면 → "방법론 선택에 따라 취약 지역이 달라진다" → 자의성 문제
- **r = 0.979** → 공간 패턴이 방법론에 독립적으로 실재 → 단순 카운트 TARR의 교차 검증

논문 서술: "분석 결과가 방법론 선택에 robust함을 확인하였다. 이는 관측된 접근성 손실 패턴이 측정 방법에 독립적인 실재 공간 현상임을 지지한다."

| 변수 | 방향 | 유의 |
|------|------|------|
| 고온 링크 비율 | + | *** |
| SVF | + | — |
| 캐노피 비율 | — | — |
| 건물 높이 | — | — |
| H/W 비율 | — | — |

**R² = 0.174** — 공간 변수가 TARR 변동의 17% 설명 (나머지는 네트워크 구조 등)

---

## 5-2. Pearson 상관계수 (r)

### 한 줄 정의
두 변수가 **얼마나 같이 움직이는지** (-1 ~ +1)

| r 값 | 해석 |
|------|------|
| +1.0 | 완벽한 양의 선형 관계 |
| +0.7 이상 | 강한 상관 |
| 0 | 무관 |
| -1.0 | 완벽한 음의 관계 |

**주의**: 상관 ≠ 인과. 방향은 이론으로 판단해야 합니다.

이 연구의 주요 r 값:
- SVF ↔ MRT: **r ≈ 0.89**
- 단순 TARR ↔ 중력모델: **r = 0.979**

**OSM (OpenStreetMap)**: 자원봉사자가 만드는 오픈소스 지도  
**osmnx**: Python에서 OSM 데이터로 네트워크 분석하는 라이브러리

| 항목 | 값 |
|------|-----|
| 네트워크 링크 | **15,608개** |
| 가중치 | travel_time = length / WALK_SPEED |
| 타입 | 무방향 (양방향 보행) |

한계: 지하도·실내 경로·아파트 단지 내부 경로 미포함

## 6-4. GTFS

General Transit Feed Specification — 대중교통 데이터 국제 표준

이 연구 활용: `stop_times_cleaned.txt` (4.4M 행) → 정류장별 노선 수 계산

```
trip_id에서 _Ord### 제거 → route_id 추출
→ stop_id별 unique route 수 카운트
→ 버스 482개 정류장 × 노선 수 (1~22개)
```

지하철은 수동 입력: 왕십리(4), 옥수(2), 나머지 5개(1)

# 🔗 전체 분석 흐름 요약

```
[데이터 수집]
Open-Meteo GHI ──Erbs──→ DNI + DHI
S-DoT 57개 ──IDW──→ 링크별 Tair, RH
OSM 건물 → 링크별 SVF
           ↓
[MRT 계산 — SOLWEIG 약식]
(SVF + DNI/DHI + Tair/RH + va) → 링크별 MRT (42~66°C)
           ↓
[임계값 설정]
UTCI 역산 → MRT 임계값 55°C
           ↓
[Catchment 계산]
전체 G → Dijkstra → Classic_cnt (15분/4.5km/h)
MRT≥55°C 링크 제거 → G_thermal → Thermal_cnt
           ↓
[TARR 계산]
TARR = (Classic - Thermal) / Classic × 100
→ 집계구 평균 72.9%, 87개 집계구 완전 차단
           ↓
[검증 1: Monte Carlo]
threshold ~ N(55, 4²), N=2000 → 95% CI: 0.3~98.3%
S자 곡선 발견 → 교량 링크 존재 시사
           ↓
[검증 2: 중력모델]
A_i = Σ S_j × Gaussian(t_ij) → 감소율 72.8%
단순 TARR와 r=0.979 → Robustness 확인
           ↓
[회귀분석]
TARR ~ SVF + 캐노피 + H/W + 건물높이 + 고온링크비율
R² = 0.174 — 공간 형태가 TARR의 17% 설명
```
